# Packages installed on the Arch machine, one per line. `# ...` is a comment.
# Split in two: official repo packages (pacman) first, then AUR packages (yay).
# `pacman -Qqm` lists what came from the AUR.
#
#   linux/packages.sh install   install whatever here is missing
#   linux/packages.sh diff      compare this list with what is installed
#
# One-time setup that isn't a package (services, groups, pacman.conf, ...)
# is in SETUP.md.
